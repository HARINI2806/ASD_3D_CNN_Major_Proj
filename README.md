# Austism-spectrum-detection using 3D CNN
 Autism Spectrum Detection
 Autism spectrum sickness (ASD), a form of neurological sickness, appears
in youngsters among 6 and 17 years of age and impacts conversation
abilties and social conduct.Early diagnosis during adolescence
is critical and might improve the social capabilities and communique
problems of youngsters with ASD and decorate their pleasant of lifestyles.
This project uses a 3D Convolutional Neural Network (CNN) model using sABIDE -Autism Brain Imaging Data Exchange dataset and predict outcomes ASD diagnosis for unseen health records. The project also aims to present a comprehensive analysis and provide some recommendations related to ASD results generated by the system
